Feature: Checkout Flow - Payment
  User story: As a customer, I want to provide payment details specific to my chosen payment method,
    so that my payment is processed correctly.

  Background:
    Given the shopper has items in the cart
    And the shopper has completed the Sign in and Billing Address steps

  Rule: A shopper can choose one of the offered payment methods

    Scenario: Payment methods are offered
      Given the shopper has not chosen a payment method
      When the shopper reaches the Payment step
      Then the shopper should be offered the payment methods Bank Transfer, Cash on Delivery, Credit Card, Buy Now Pay Later and Gift Card

    Scenario: Confirming the payment without a payment method
      Given the shopper has not chosen a payment method
      When the shopper confirms the payment
      Then the shopper should be told that a payment method must be chosen
      And the shopper should not be able to place the order

    Question parked: Confirm whether any payment method is already chosen for the shopper on arrival at the Payment step with the Product Owner or Business Analyst.
    Question parked: Confirm whether any payment method is offered only for certain order totals or billing countries with the Product Owner or Business Analyst.

  Rule: Bank Transfer needs a bank name, an account name and an account number

    Scenario: Bank Transfer details are requested
      Given the shopper has not chosen a payment method
      When the shopper chooses Bank Transfer
      Then the shopper should be asked for the bank name, account name and account number

    Scenario Outline: A bank name of letters and spaces is accepted
      Given the shopper has provided every Bank Transfer detail except the bank name
      When the shopper provides the bank name <bank name>
      Then the shopper should be able to place the order

      Examples:
        | bank name       |
        | Barclays        |
        | Bank of America |

    Scenario Outline: A bank name with other characters is rejected
      Given the shopper has provided every Bank Transfer detail except the bank name
      When the shopper provides the bank name <bank name>
      Then the shopper should be told that the bank name is not valid
      And the shopper should not be able to place the order

      Examples:
        | bank name  |
        | Bank 2     |
        | Lloyds-TSB |
        | Barclays!  |

    Scenario Outline: An account name of letters, digits, spaces, periods, apostrophes and hyphens is accepted
      Given the shopper has provided every Bank Transfer detail except the account name
      When the shopper provides the account name <account name>
      Then the shopper should be able to place the order

      Examples:
        | account name     |
        | Jane Smith       |
        | J. Smith         |
        | Sean O'Brien     |
        | Mary-Jane Smith  |
        | Smith Holdings 2 |

    Scenario Outline: An account name with other characters is rejected
      Given the shopper has provided every Bank Transfer detail except the account name
      When the shopper provides the account name <account name>
      Then the shopper should be told that the account name is not valid
      And the shopper should not be able to place the order

      Examples:
        | account name |
        | Jane@Smith   |
        | Jane_Smith   |
        | Smith, Jane  |

    Scenario Outline: An account number of digits only is accepted
      Given the shopper has provided every Bank Transfer detail except the account number
      When the shopper provides the account number <account number>
      Then the shopper should be able to place the order

      Examples:
        | account number |
        | 12345678       |
        | 0012345678     |

    Scenario Outline: An account number with other characters is rejected
      Given the shopper has provided every Bank Transfer detail except the account number
      When the shopper provides the account number <account number>
      Then the shopper should be told that the account number is not valid
      And the shopper should not be able to place the order

      Examples:
        | account number |
        | 1234-5678      |
        | 1234 5678      |
        | 12345A78       |

    Scenario Outline: A required Bank Transfer detail is left out
      Given the shopper has chosen Bank Transfer
      When the shopper provides every Bank Transfer detail except the <detail>
      Then the shopper should be told that the missing detail is required
      And the shopper should not be able to place the order

      Examples:
        | detail         |
        | bank name      |
        | account name   |
        | account number |

    Question parked: Confirm the minimum and maximum length of the bank name with the Product Owner or Business Analyst.
    Question parked: Confirm the minimum and maximum length of the account name with the Product Owner or Business Analyst.
    Question parked: Confirm the minimum and maximum number of digits in the account number with the Product Owner or Business Analyst.
    Question parked: Confirm whether a bank name or account name made up only of spaces is accepted with the Product Owner or Business Analyst.

  Rule: Buy Now Pay Later needs a number of monthly instalments

    Scenario: Monthly instalment options are offered
      Given the shopper has not chosen a payment method
      When the shopper chooses Buy Now Pay Later
      Then the shopper should be offered 3, 6, 9 or 12 monthly instalments
      And the shopper should not be asked for any other payment details

    Scenario Outline: An offered number of monthly instalments is accepted
      Given the shopper has chosen Buy Now Pay Later
      When the shopper chooses <instalments> monthly instalments
      Then the shopper should be able to place the order

      Examples:
        | instalments |
        | 3           |
        | 6           |
        | 9           |
        | 12          |

    Scenario: No number of monthly instalments is chosen
      Given the shopper has chosen Buy Now Pay Later
      And the shopper has not chosen a number of monthly instalments
      When the shopper confirms the payment
      Then the shopper should be told that a number of monthly instalments must be chosen
      And the shopper should not be able to place the order

    Question parked: Confirm whether the shopper is told the amount of each monthly instalment before placing the order with the Product Owner or Business Analyst.
    Question parked: Confirm whether Buy Now Pay Later is limited to a minimum or maximum order total with the Product Owner or Business Analyst.
    Question parked: Confirm whether any interest or fee is added to the order total for Buy Now Pay Later with the Product Owner or Business Analyst.

  Rule: Cash on Delivery needs no payment details

    Scenario: No details are requested for Cash on Delivery
      Given the shopper has not chosen a payment method
      When the shopper chooses Cash on Delivery
      Then the shopper should not be asked for any payment details

    Question parked: Confirm whether Cash on Delivery is limited to a maximum order total with the Product Owner or Business Analyst.

  Rule: Changing the payment method clears the details provided for the earlier method

    Scenario: Details are gone after changing back to the earlier payment method
      Given the shopper has chosen Bank Transfer
      And the shopper has provided the bank name Barclays, account name Jane Smith and account number 12345678
      And the shopper has changed the payment method to Gift Card
      When the shopper changes the payment method back to Bank Transfer
      Then the shopper should have to provide the bank name, account name and account number again

    Question parked: Confirm whether the shopper is warned before the details provided are cleared by a change of payment method with the Product Owner or Business Analyst.

  Rule: Payment details are cleared when the shopper leaves the Payment step

    Scenario: Details are gone when the shopper comes back to the Payment step
      Given the shopper's cart holds 2 claw hammers priced at $12.50 each
      And the shopper has provided Credit Card details
      When the shopper comes back to the Payment step after leaving it
      Then the shopper should have to provide the payment details again
      And the cart total should still be $25.00

    Question parked: Confirm whether the chosen payment method is kept when the shopper comes back to the Payment step with the Product Owner or Business Analyst.

  Rule: Confirming the payment with every required detail places the order

    Scenario Outline: The order is placed
      Given the shopper has chosen <payment method>
      And the shopper has provided every detail that <payment method> requires
      When the shopper confirms the payment
      Then the shopper should be told that the order has been placed
      And the shopper should be given an invoice number for the order

      Examples:
        | payment method    |
        | Bank Transfer     |
        | Cash on Delivery  |
        | Credit Card       |
        | Buy Now Pay Later |
        | Gift Card         |

    Scenario Outline: The cart is empty after the order is placed
      Given the shopper has chosen <payment method>
      And the shopper has provided every detail that <payment method> requires
      When the shopper confirms the payment
      Then the shopper's cart should be empty

      Examples:
        | payment method    |
        | Bank Transfer     |
        | Cash on Delivery  |
        | Credit Card       |
        | Buy Now Pay Later |
        | Gift Card         |

    Scenario Outline: A order confirmation email is sent
      Given the shopper with the email address jane.smith@example.com has chosen <payment method>
      And the shopper has provided every detail that <payment method> requires
      When the shopper confirms the payment
      Then the shopper should receive a checkout confirmation email for the order at jane.smith@example.com

      Examples:
        | payment method    |

        | Gift Card         |
