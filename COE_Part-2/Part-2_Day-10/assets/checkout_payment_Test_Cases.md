## Notes before running

1. The happy-path cases (TS-02 to TS-06) check the confirmation email, so they need a test customer whose email address is a real test mailbox the tester can read. example.com addresses cannot receive mail.
2. The acceptance criteria only list expiration date forms that are rejected, never the accepted form, so the cases that accept MM/YYYY with a month from 01 to 12 (TS-27) rest on an assumption.
3. Expiration dates that depend on today are written relative to the current month, with an example for October 2026. Fixed dates such as 01/2027 assume the test is run in 2026; use a later year if it is run after December 2026.
4. Before each case, reset the cart to the state given in its Preconditions, because most cases place or try to place an order.
